The **Optimage** is a modern, feature-rich web application designed for efficient image compression and visualization. Built with **React**, **TypeScript**, and **Tailwind CSS**, it provides a responsive and visually appealing user interface while maintaining high performance and modularity.

---

## 🚀 **Features**

### 🔧 **Image Compression**
- Utilizes the `browser-image-compression` library for efficient image compression.
- Supports both **lossy** (JPEG, WebP) and **lossless** (PNG) formats.
- Offers customizable compression options:
  - Resize dimensions.
  - Adjust quality levels.
  - Handle various image types.

### 📂 **File Management**
- Tracks the state of uploaded files using React hooks (`useRef`, `useState`).
- Efficiently manages memory by maintaining references to original and compressed file URLs.

### 📊 **Chart Visualization**
- Integrates the `recharts` library for dynamic charting.
- Supports light and dark themes with customizable styles.
- Includes tooltips and legends with options for icons, labels, and indicators.

### 🎨 **UI Components**
- Built with a modular, component-based architecture.
- Includes reusable UI elements like buttons, sliders, switches, and progress bars.
- Styled with **Tailwind CSS** for a clean, modern look.

### 🌐 **Accessibility and Responsiveness**
- Uses semantic HTML and React components for accessibility.
- Fully responsive with grid-based layouts and flexible scaling.

---

## 🛠️ **Tech Stack**

- **Frontend Framework**: React with TypeScript for type safety.
- **Styling**: Tailwind CSS with support for dynamic theming.
- **Build Tool**: Vite for fast development and optimized builds.
- **Charting**: Recharts for interactive data visualization.
